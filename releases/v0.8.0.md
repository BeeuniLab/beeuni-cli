# Beeuni v0.8.0

- Update CLI and TUI support for Goals, session controls, permissions and attachments.
- Keep terminal caches separate when switching accounts.
- Update SDK session history, recovery and runtime state handling.
- Enable My Beeuni by default in newly initialized projects, alongside Worker.
- Refresh bundled skills and document-review scripts.
- Update desktop installers to 0.3.3 with update-restart and deep-link handling fixes, plus Windows quick-entry improvements.

## Migration notes

SDK 0.8.0 removes retired subpath aliases and artifact collaboration, comment and activity APIs. Use exports from `@beeuni/sdk` and `@beeuni/sdk/react`, and use `useSession` for session actions. File reads, saves and version conflict checks remain available. Review these changes before upgrading an existing integration.

The CLI also removes the artifact commands `comments`, `comment`, `reply`, `resolve`, `reopen`, `activity` and `focus`. Artifact publishing, sharing, reads and version commands remain available.

## Downloads

CLI and TUI binaries are version 0.8.0 for macOS and Linux, on arm64 and x64. Desktop installers are version 0.3.3 for macOS Universal, Windows x64 and Linux arm64/x64.

The SDK and its model catalog dependency use version 0.8.0. Computer connection tools remain at 0.1.5 because their published files have not changed. Capture is not included in this release. Existing projects keep their own agent configuration; the new default applies to newly initialized projects.
