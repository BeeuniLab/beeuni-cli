## Beeuni v0.3.0

- Search Capture history and inspect timelines and frames from the CLI and SDK.
- Create and update Apps that open an external URL.
- Get more reliable session recovery, model selection, and live message updates.
- Use the updated model catalog with current model options.
- Use native right-click menus for text, links, and images in the desktop app.
- Upgrade existing projects to the current configuration format from the CLI.

CLI and TUI binaries are available for macOS and Linux. Desktop installers are available for macOS, Windows, and Linux.
