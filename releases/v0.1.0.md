## Beeuni CLI v0.1.0

### Included

- Beeuni command-line client distribution for macOS and Linux.
- Desktop application installers for supported desktop platforms.
- Automatic platform and architecture detection in the installer.
- SHA256 checksums for downloaded CLI binaries.
- Browser-based sign-in and project management commands.

### Release artifacts

- CLI binaries for macOS and Linux on arm64 and x64.
- Desktop installers and update metadata.
- SHA256 checksums for the CLI binaries.
