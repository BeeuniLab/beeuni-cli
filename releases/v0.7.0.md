# Beeuni v0.7.0

- Add project spaces and search commands to the CLI. Spaces replace the former rooms and peers commands.
- Show usage and reset information for connected model subscriptions.
- Update CLI, TUI and SDK support for workflows, background agents, App events and session startup.
- Add SDK support for collaborative artifacts, live edits and comments.
- Update the built-in coding, search and document-review skills.

This release contains CLI and TUI binaries for macOS and Linux, on arm64 and x64. The SDK and model catalog use version 0.7.0.

Desktop installers remain at version 0.3.2 and are copied unchanged from v0.6.2. The newer desktop navigation rule is not included. Computer connection tools remain at version 0.1.5. Capture is not distributed in this release.

The separately released Beeuni VOXL desktop streamer is now pinned to 0.3.3-beeuni.1 in the platform's sandbox images. These CLI downloads do not replace an existing sandbox image.
